# Nexora — Career Operating System

Watch your career actually move.

Nexora is a unified career SaaS: job search and internships, AI matching, ATS resume studio, application tracker, interview rehearsal, learning OS, professional graph, recruiter pipeline, campus placements, and a people OS.

## Portals

- **Seeker** — progress line, jobs ranked by fit, internships, tracker, resume, interviews, salary intelligence
- **Hire** — requisitions, kanban pipeline, talent intelligence, people OS
- **Campus** — student talent pool and placement drives
- **Community** — feed + learning OS

## Stack

TanStack Start, React 19, Tailwind v4, Better Auth, Postgres (Neon / PGLite).

Sign in with Google, X, or email, then enter a portal.
